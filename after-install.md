# RyzeAPI installed

Author: Neriton Dias · Instagram @neritondias · beta 1.0.0-beta.1.

1. Read README.md and docs/INSTALL.md. Português: README.pt-BR.md and docs/INSTALL.pt-BR.md.
2. Install requirements.txt with the Hermes Python interpreter, configure dashboard authentication and HTTPS webhook routing, then enable ryzeapi.
3. On the enabled plugin's first load, both skills are installed automatically: ryzeapi (conversation/API) and ryzeapi-painel (dashboard).
4. Open a new session and verify skills_list, /ryzeapi and /ryzeapi-painel.
5. Configure credentials, WhatsApp and the firewall in your authenticated dashboard. No number or group is authorized automatically.

Customized skills are preserved with a conflict warning. No separate skill installation is required.

Independent community project. Installation does not configure your account or send messages. Read the README for limitations and the native WhatsApp migration checklist; this beta does not promise complete feature parity.
